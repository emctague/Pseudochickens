# pseudochickens

This is a Minecraft server plugin that introduces pseudo-chicken farms.
These compact the behaviour of a chicken farm down into a single block, providing all the benefits of a compact chicken
farm without the lag.

### Compatibility

The plugin targets Spigot and Paper for Minecraft 26.2.
It should be very broadly compatible with other versions if compiled for them.

### Usage

To create a pseudofarm, right-click on the ground with a feather.
The pseudofarm will appear as a chicken spawner.

Pseudofarms start with zero chickens. To add a chicken to the farm, right-click on the farm with an egg.

Over time, your chickens will lay eggs. They do so at the average rate that regular chicken entities will, which means
one egg per chicken every 7.5 minutes.

Right-click on the pseudofarm to take one egg out of it, if any are there.
This will also tell you how many chickens are in the farm.

Chickens in the farm can be killed for meat and feathers, with roughly the same drop rates as a regular chicken entity.
To kill one chicken, left-click on the farm.

If you want to break the farm block instead of killing a chicken, crouch.
